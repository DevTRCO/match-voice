# match-voice

Real-time football commentary in several languages and styles, generated from synthetic match events,
with every sentence checked against the facts before it is spoken.

Built for the Microsoft x Premier League "Inside the Game: Developer Hackathon". All teams, players and
matches are fictional and generated by this project.

> Work in progress. The generator, fact engine, commentary agents and verifier work and are tested.
> The live server and the single-screen UI are next.

## How it works

1. **Ingest:** a synthetic match generator produces about 2,000 football events per match
   (passes, shots, tackles, pressure, fouls, cards) around a scripted story arc, plus a ground-truth file.
2. **Interpret:** the fact engine keeps live match state (possession, xG, momentum, win probability)
   and turns events into facts that carry the event ids they follow from.
3. **Explain:** play-by-play comes from templates (no model, milliseconds). Analysis comes from an
   Analyst agent (Microsoft Agent Framework, Claude as the model). A Verifier checks every line for
   invented numbers, wrong scorelines, wrong players, wrong language and length. Rejected lines go back to
   the Analyst with the reason; if the retry fails, a template line takes over.
4. **Render / Personalize:** a Director schedules one voice per language and style under a speech-time
   budget, keeps silence when nothing matters, and interrupts for goals and red cards.
   Languages: en, de, fr. Styles: beginner, expert.

## Run it

Requires Python 3.11 or newer.

```bash
python3 -m venv .venv
source .venv/bin/activate            # Windows: .venv\Scripts\activate
pip install -e ".[dev]"
python -m pytest -q

python -m matchvoice.sim --arc comeback --seed 7      # generate a match into data/matches
python -m matchvoice.facts data/matches/comeback-7     # key moments and win probability
```

Model calls need an Anthropic API key in a git-ignored `.env` file at the repository root
(`ANTHROPIC_API_KEY_2=...`). The tests and everything except the analyst run without a key.
